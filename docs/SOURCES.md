# Sources and assets

## Character

- Author: **Quaternius**.
- Pack: [Universal Animation Library](https://quaternius.com/packs/universalanimationlibrary.html).
- Download: [the author's itch.io page](https://quaternius.itch.io/universal-animation-library),
  free Standard edition, downloaded 2026-09-26.
- Original file: `Universal Animation Library[Standard]/Unreal-Godot/UAL1_Standard.glb`.
- Local file: `public/assets/quaternius-ual.glb`, original binary without conversion.
- SHA-256: `69591853d817488edaa8fd9bf8fc1d821eaeaf789f8627b3cd23b41c4ed67997`.
- License: **CC0 1.0 Universal**; original license included as
  `public/assets/LICENSE-Quaternius.txt`.
- The pack includes a skinned mannequin; no separate character purchase is required.
- Used clips: `Idle_Loop`, `Walk_Loop`, `Sprint_Loop`. The other supplied clips remain
  in the source asset. This is the non-root-motion version; the controller moves
  the model, and the mixer animates its skeleton. Material colors are changed at runtime.

## Rendering

- [three-mesh-bvh](https://github.com/gkjohnson/three-mesh-bvh), Garrett Johnson,
  MIT license. The static terrain uses its spatial index for brush picking;
  the license is included in `public/assets/LICENSE-three-mesh-bvh.txt`.
- [Three.js animation system](https://threejs.org/manual/pages/animation-system.html).
- [Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html).
- [Three.js renderer counters](https://threejs.org/docs/pages/WebGLRenderer.html):
  manually reset once per frame to include both shadow and main rendering passes.
- [WebGL 2 disjoint timer queries](https://registry.khronos.org/webgl/extensions/EXT_disjoint_timer_query_webgl2/):
  GPU elapsed time in nanoseconds, read only after asynchronous availability.
- Terrain geometry, colors, path, landmarks, grass cutouts, rain seeds, sky and
  reflection environment are generated by this project; they use no external images.
- [Physically based wet surfaces — Sébastien Lagarde](https://seblagarde.wordpress.com/2013/03/19/water-drop-3a-physically-based-wet-surfaces/):
  surface layers, porous materials and the limits of simple darkening.
- [Three.js physical material](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)
  and [PMREM filtering](https://threejs.org/docs/pages/PMREMGenerator.html):
  coating, roughness and prefiltered environment lighting in study 09.

## Browser input boundaries

- [Mozilla: contextmenu](https://developer.mozilla.org/en-US/docs/Web/API/Element/contextmenu_event):
  Firefox Shift+right-click bypasses the event and forces the browser menu.
- [Mozilla bug 1891843](https://bugzilla.mozilla.org/show_bug.cgi?id=1891843):
  native context menus can consume key releases before web content receives them.
- [Mozilla preference discussion](https://support.mozilla.org/en-US/questions/1420135):
  `dom.event.contextmenu.shift_suppresses_event=false` permits cancelling that chord.
  Isolated Firefox tests use this preference; the personal profile is untouched.
- Regression tests exercise sprint + orbit and deliberately drop key releases to
  verify pointer-cancellation recovery.
